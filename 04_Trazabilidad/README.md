# Trazabilidad de Requisitos

Esta carpeta contiene la matriz de trazabilidad utilizada para verificar la relación entre los requisitos y los diferentes artefactos del proyecto.

La matriz permite identificar relaciones entre:
- Requisitos funcionales y no funcionales
- Casos de uso
- Historias de usuario
- Tareas de ingeniería
- Casos de prueba
- Artefactos relacionados
- Componentes o módulos asociados

También incluye los metadatos necesarios para la gestión del ciclo de vida de los artefactos:
- ID único
- Versión
- Estado final
- Autor o revisor
- Fecha de cierre
- Artefactos relacionados

La matriz se utiliza como evidencia para la auditoría de trazabilidad y la gestión del conocimiento.
